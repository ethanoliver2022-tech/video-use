# Orbit Bonk

A knockback brawler for Roblox. It's inspired by "knock everyone off the island" games, but it has its own look and adds more systems:

- **Neon space arena.** A floating disc of hexagon tiles drifts above planets and asteroids. Starting at 0:35, the outer ring falls away every 14 seconds until only the centre tile is left.
- **Smash-style damage %.** Each hit raises your %, and a higher % means you fly further. The blast zones are below the arena, at the sides and above it.
- **Hammer combat.** You get a cone swing, a **dash (Q)** that also works mid-air for recovery, a **shockwave slam (E)** and a **double jump**.
- **Power-up orbs:**
  - **Mega Bonk** gives +70% launch power.
  - **Zoom** gives super speed.
  - **Bubble** blocks one hit.
  - **Feather** gives big jumps and heals 15%.
- **BonkBots.** Rounds are topped up to 6 fighters with AI bots, so one player can still play. Each bot has its own skill level. Bots avoid walking off edges and try to recover when knocked off.
- **KO credit, kill feed, MVP and placements.** Coins come from KOs, top-3 finishes and wins.
- **Hammer shop.** There are 7 skins, all cosmetic, so purchases never change balance. Coins, wins, KOs and skins are saved with DataStores.
- **Feel.** Hits get BONK! popups, particle bursts, camera shake and hit-stop, plus a KO blast line, victory fireworks and spectating with a camera on the winner.
- **Controls.** Works with keyboard/mouse, touch (on-screen DASH/SLAM buttons) and gamepad (X = dash, Y = slam).

Everything is generated by scripts. The place file contains no model or image assets, so there's nothing to fail moderation or go missing.

## Fastest way to play: open the place file

1. Download `build/OrbitBonk.rbxlx`.
2. Open it in **Roblox Studio** (File → Open from File).
3. Press **Play** to test it. Bots will fill the round.
4. Go to **File → Publish to Roblox**, create a new experience, and it's live.
5. To save progress, go to **Game Settings → Security** and turn on **Enable Studio Access to API Services** (only needed for Studio testing; published games always have DataStores).

## Direct upload from the command line (Open Cloud)

1. Create the experience once (step 4 above, or on create.roblox.com) and note its **Universe ID** and **Place ID**.
2. On create.roblox.com → Credentials, create an API key with **universe-places: write** for that experience.
3. Run:
   ```bash
   export ROBLOX_API_KEY=your_key
   python3 publish.py --universe <UNIVERSE_ID> --place <PLACE_ID>
   ```

## Developing

The source is a [Rojo](https://rojo.space) project:

```
src/shared/Config.luau          every tuning number, skins, colours
src/server/Main.server.luau     round loop (lobby -> countdown -> brawl -> results)
src/server/Combat.luau          fighters, hits, knockback, KO credit
src/server/Arena.luau           hex arena + ring collapse
src/server/Bots.luau            BonkBot AI
src/server/PowerUps.luau        orb spawning + effects
src/server/Hammer.luau          hammer tool / bot hammer
src/server/Data.luau            DataStore profiles + shop
src/server/World.luau           lobby, lighting, space backdrop
src/client/Main.client.luau     controls, knockback physics, HUD wiring, spectate
src/client/UI.luau              HUD, shop, results
src/client/Effects.luau         particles, popups, shake, sounds
```

Rebuild the place file with `rojo build default.project.json -o build/OrbitBonk.rbxlx`. To live-sync into Studio, use `rojo serve` with the Rojo plugin.
